# Student-Management-system
Abstract
The Student Record Management System is 
a desktop-based application developed 
using Java (Swing) and MySQL database. The 
main objective of this system is to manage 
student records efficiently through a user
friendly graphical interface.
This system allows users to perform basic 
database operations such as Add, Update, 
Clear and Delete (CRUD) student details. It 
reduces manual work, improves accuracy, 
and ensures secure storage of data.
Objectives:
To develop a GUI-based application using Java 
Swing
To implement database connectivity using JDBC
To perform CRUD operations on student data
To provide a simple and efficient user interface
Technologies Used:
Programming Language: Java
GUI Framework: Swing (AWT)
Database: MySQL
Connectivity: JDBC
1. Presentation Layer
User interacts with GUI (buttons, 
text fields)
Built using Swing components like 
JFrame, JButton, JTextField
2.Application Layer
Contains logic for CRUD operations
Uses JDBC to connect Java with 
MySQL
3.Database Layer
Stores student records in table 
format
Handles data storage and retrieval
8. Applications
Used in schools and colleges to 
manage student data
Helps in maintaining records digitally
Reduces paperwork and manual errors
Can be extended for attendance, 
marks, etc.
The Student Record Management System 
successfully demonstrates the use of Java 
Swing for GUI and JDBC for database 
connectivity. It provides an efficient way to 
manage student records and can be enhanced 
further with advanced features like search, 
login system, and report generation.
The system fulfills all basic requirements of 
record management and can be further 
enhanced to develop a complete student
management solution.
